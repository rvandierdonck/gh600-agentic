## Current homepage themes

- GitHub collaboration basics: repositories, branches, pull requests, and merges.

## Recent updates (November 2026)

Pull requests and collaboration:

- A new pull request overview page is in public preview, with follow-up improvements. ([Nov 5](https://github.blog/changelog/2026-11-05-new-pull-request-overview-page-in-public-preview), [Nov 19](https://github.blog/changelog/2026-11-19-improvements-on-the-pull-request-overview-in-public-preview))
- You can pin your favorite repositories to your dashboard. ([Changelog](https://github.blog/changelog/2026-11-20-pin-your-favorite-repositories-to-your-dashboard))
- GitHub CLI can wait for pull request events. ([Changelog](https://github.blog/changelog/2026-11-18-wait-for-pull-request-events-with-github-cli))

GitHub Copilot:

- Customize GitHub Copilot for your team. ([Changelog](https://github.blog/changelog/2026-11-18-customize-github-copilot-for-your-team))
- Connect more tools, such as Supabase, Box and Calendly, to Copilot. ([Changelog](https://github.blog/changelog/2026-11-18-connect-supabase-box-calendly-and-more-to-copilot))
- Track Copilot code review outcomes in repository insights. ([Changelog](https://github.blog/changelog/2026-11-17-track-copilot-code-review-outcomes-in-repository-insights))
- Copilot is now available in Xcode and JetBrains Air. ([Xcode](https://github.blog/changelog/2026-11-04-github-copilot-is-now-available-in-xcodes-coding-assistant), [JetBrains Air](https://github.blog/changelog/2026-11-03-github-copilot-is-now-available-in-jetbrains-air))

GitHub Actions and security:

- `pull_request_target` workflows are blocked by default starting in December; review workflows that use it. ([Changelog](https://github.blog/changelog/2026-11-02-pull_request_target-blocked-by-default-december-2))
- Red Hat Enterprise Linux runner images are generally available. ([Changelog](https://github.blog/changelog/2026-11-19-red-hat-enterprise-linux-runner-images-now-generally-available))
- Secret scanning on demand is available for developers and agents. ([Changelog](https://github.blog/changelog/2026-11-17-secret-scanning-on-demand-for-developers-and-agents))

More: [GitHub Changelog](https://github.blog/changelog/) and [GitHub Blog](https://github.blog/latest/), including [How AI code generation works](https://github.blog/ai-and-ml/generative-ai/how-ai-code-generation-works/).
